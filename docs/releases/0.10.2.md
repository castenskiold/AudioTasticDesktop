AudioTastic 0.10.2 lets files opened from Explorer replace the playlist instead of being added to it, and makes the playlist easier to read. Everything else is as in [0.10.1](https://github.com/castenskiold/AudioTasticDesktop/releases/tag/v0.10.1).

Also attached: the optional OptimFROG plugin (`AudioTastic.Input.OptimFrog.atplugin`, Windows x64, Linux x64, macOS Intel; install it with *Settings › Plugins › Install*), the sources of the bundled FFmpeg libraries (`AudioTastic-0.10.2-ffmpeg-sources.tar`), and `SHA256SUMS.txt` with the checksums of every file.

- **Windows:** the setup installs for your user only (no administrator rights) and adds Start menu entries for AudioTastic and the User Manual. The portable zip keeps settings next to the program. Neither is code-signed yet, so SmartScreen may say the publisher is unknown: choose *More info › Run anyway*.
- **macOS:** open the `.dmg` and drag AudioTastic to Applications. The app is not signed or notarized: allow it once in *System Settings › Privacy & Security*, or run `xattr -dr com.apple.quarantine /Applications/AudioTastic.app`.
- **Linux:** make the AppImage executable (`chmod +x`) and run it; needs a desktop with X11 or XWayland.

Upgrading from 0.10.x: install over it (or replace the portable folder); your settings and playlists are kept. The [User Manual](https://github.com/castenskiold/AudioTasticDesktop/blob/main/docs/manual/README.md) also comes as a PDF next to the program.

## New

- **Replace the playlist when opening files:** *Settings › System integration › When opened files are played* chooses whether files you double-click in Explorer (or open with *Open in AudioTastic* or `--open`) are added to the active playlist, as before, or replace it. Replacing is one step that **Ctrl+Z** in the playlist undoes. Enqueued files are always added.

## Changed

- **Larger playlist text:** the track list, search box and totals use a larger font, and the rows are taller.
- **Playlist rows start at the left:** the track numbers take only the room the playlist's longest number needs, so titles start right after them instead of after a wide empty column.
