AudioTastic 0.10.0 adds system integration and installers (phase P10), casting to Chromecast and DLNA TVs (phase P11), VST3 effects (phase P12), file conversion, settings backup and accessibility (phase P13), and release hardening (phase P14): a 24-hour playback test without a dropout, tests with thousands of damaged files, and our own smaller FFmpeg build.

## New

- **Single instance:** AudioTastic runs once per user. Opening files while it runs sends them to the running player, which brings itself to the front. Files opened together, e.g. several selected in Explorer, are added as one batch, sorted by path.
- **Notifications (Windows):** optional notification with the title, artist and cover when the track changes, skipped while AudioTastic is in front (*Settings › Interface*, off by default).
- **Taskbar (Windows):** previous / play-pause / next buttons under the taskbar preview, and green (playing) or yellow (paused) progress on the taskbar button, which can be switched off.
- **Global hotkeys (Windows):** Ctrl+Alt+Home play/pause, Ctrl+Alt+End stop, Ctrl+Alt+PgUp/PgDn previous/next and Ctrl+Alt+Up/Down volume work while another program is in front. Switch them off or change them (twelve actions) in *Settings › System integration › Global hotkeys*; a combination another program already uses is marked.
- **Media controls (Windows):** AudioTastic shows in the Windows media flyout with the title, artist and cover (or its logo); the flyout's buttons, keyboard media keys and headset buttons control it, even when it is hidden. A Start menu shortcut is created (needed for Windows to show the app's name; switch it off in *Settings › System integration*).
- **Tray icon:** hover for the title, click to hide or show the player with its docked windows, right-click for Play/Pause, Stop, Previous, Next, a sleep timer (15 minutes to 2 hours, end of track or playlist), Show/Hide and Exit. Optional minimise and close to the tray (*Settings › System integration › Tray*).
- **File types (Windows):** the first start asks whether to use AudioTastic for audio files. *Yes, set up* registers it for every audio and playlist type it plays and opens *Settings › Default apps*, where you make it the default; double-clicked files then go to the running player. *Settings › System integration › Choose default apps…* does the same later; switching the registration off removes it.
- **Explorer context menu (Windows):** *Open in AudioTastic* (adds the files and plays the first) and *Enqueue in AudioTastic* (adds them to the end of the playlist), with the app icon, for every audio and playlist type the enabled plugins support. On Windows 11 they are under *Show more options*. Per user, no administrator rights; switch them off in *Settings › System integration* before deleting the program.
- **Command line:** files with `--open` or `--enqueue`, and player commands for scripts and shortcuts: `--play`, `--pause`, `--playpause`, `--stop`, `--next`, `--prev`, `--volume N`, `--seek s`, `--quit`. They go to the running player (or start it; `--stop`, `--pause` and `--quit` do nothing when no player runs). On Windows they can also be written `/next`, `/volume 40`. `--help` and `--version` print to the console.
- **Settings › System integration:** files opened from the file manager or the command line are played (default) or enqueued; the context menu on/off (off by default in portable mode).

- **Resizing snaps:** resizing the playlist or Art & Lyrics window by its corner lines its right and bottom edges up with the player and other windows (and the screen edge) within 10 px, like moving does.

- **Installers:** a Windows setup (per user, no administrator rights, Start menu and uninstall entries; uninstalling removes the file types and context menu entries), a macOS `.dmg` with AudioTastic.app, and a Linux AppImage. The zips and tarballs remain.
- **`--unregister`:** removes everything AudioTastic registered with the system (used by the uninstaller).

- **Cast to Chromecast and DLNA:** the CAST button (or *Main menu › Cast to…*) lists the cast devices on your network. Choosing a Chromecast or a DLNA device (smart TVs, network receivers) moves the playing track there at the same position; play, pause, seek, next/previous and volume control the device, and the playlist continues on it. *This computer* brings playback back. Files a device can't play are converted on the fly (FLAC for Chromecast, WAV for DLNA TVs); title, artist, album and cover show on the TV. A DLNA TV keeps its own volume when casting starts, and the volume slider moves it from there. AudioTastic serves the audio from a small built-in web server that answers only devices on your local network; Windows may ask to allow it through the firewall. Its port can be fixed in *Settings › Casting & network*. AirPlay is not supported yet.
- **Audio and video on a TV:** for a Chromecast or a TV with a screen, *CAST › the TV › Audio and video* sends the player's own mix (gapless playback, crossfades and the equalizer included) together with the visualisation, so sound and picture always match. The player keeps the controls; the TV plays about two seconds behind it. The volume slider sets the TV's volume.
- **Visuals on a TV:** for a Chromecast or a TV with a screen, the CAST picker offers *Visuals only*: the spectrum analyser, the oscilloscope or a visualisation plugin is shown on the TV while the music keeps playing on the computer. Choose the visualisation, resolution (720p or 1080p) and frame rate in *Settings › Casting & network › Video on a TV*. A TV shows the picture about two seconds late, so AudioTastic draws it from the music that far ahead and the picture matches the speakers. To fine-tune a TV, open *CAST › the TV › Picture delay…*: while it is open the TV flashes white on every kick. Internet radio cannot be read ahead, so there the picture trails.

- **VST3 effects:** VST3 audio effects (free or bought) join the DSP chain: *DSP chain › Add VST3 effect…*, with the plug-in's own editor (*Open editor*). Their settings are kept with the chain. AudioTastic finds them in the standard VST3 folders and any you add in *Settings › Equalizer & DSP*; a plug-in that crashes while being scanned is set aside (blacklisted) instead of taking the player down.

- **Convert files:** select tracks in the playlist, right-click › *Convert…*, and write them as FLAC, Apple Lossless, WAV, MP3 (constant or variable bit rate), AAC, Opus or Ogg Vorbis. Tags and the cover come along; CUE tracks become separate files. Choose the folder (or next to the originals), a file name pattern such as `%albumartist%/%album%/%track% - %title%` (with a live example), and what to do when a file exists (skip, replace or number it). Several files are converted at once, with a progress list; stopping removes unfinished files. The original is never overwritten.
- **Settings backup:** *Settings › General › Export settings…* writes your settings, playlists, equalizer presets, DSP chain (with VST3 effects), hotkeys and installed skins to one `.atbackup` file. *Import settings…* shows what the file holds and lets you choose (per settings group, playlists, presets, skins); AudioTastic then restarts to apply it. What the import replaces is saved first to the `backups` folder in the data folder. Backups from older versions are upgraded; caches are not included.
- **Discogs lookup (optional):** with your own free Discogs token (discogs.com › Settings › Developers; paste it in *Settings › Metadata* and switch Discogs on), *Look up online…* asks Discogs first for the album, album artist, year, genre, track and disc number and the cover, and falls back to MusicBrainz and the Cover Art Archive when Discogs has nothing. The token stays in your settings file and is left out of settings exports.
- **VST3 effects:** the time display, waveform and lyrics now allow for the delay of effects that look ahead (a plug-in's reported latency and the built-in limiter), and plug-ins' meters move in their editors.
- **Keyboard and screen readers:** every control in the player, playlist and equalizer can be reached with Tab and shows a thin outline; Enter or Space presses it and the arrow keys move sliders (volume, position, equalizer bands). *Alt+F* opens the main menu. Screen readers such as Narrator read each control's name, state and value ("Shuffle, off", "Volume, 80 %", "Position, 1:23 of 7:31") and its shortcut key, read playlist rows as "3. Artist – Title, 5:59", and announce a new track. Skins can set the outline colour (`focus`).

- **User Manual:** `docs/manual/README.md` describes every window, menu and setting, with screenshots; the same manual as a PDF (`AudioTastic_User_Manual.pdf`) ships next to the program, and the Windows setup adds it to the Start menu.
- **Downloads:** the Windows zip is now the portable edition (`-portable.zip`, settings kept next to the program), and every release lists the SHA-256 checksums of its files in `SHA256SUMS.txt`.

## Changed

- **Our own FFmpeg build** on every platform: only what an audio player needs (all audio decoders, the encoders used for conversion and casting), built from source under LGPL-2.1. The license texts of everything inside now ship with it, releases include its sources, and the download is smaller. On macOS it also adds MP3, Opus and Vorbis conversion, HTTPS radio streams and video casting, which the earlier macOS build lacked.

- **Plugin SDK 1.0.0**, the first stable version: from now on a plugin built for SDK 1.y runs on every AudioTastic with SDK 1.z where z ≥ y, and plugins built for the 0.4 previews keep working. It has exactly the contracts of 0.4.3; a generated reference lists every type (`docs/plugins/sdk-reference.md`). SDK 0.4.3 (additive): encoders can write Opus, AAC, ALAC, Vorbis and WAV and MP3 with a variable bit rate, and tell the player which sample rate and channels they take (`IAudioEncoderFactory.InputFormatFor`). SDK 0.4.2: visualisation plugins can draw frames without a window (`IOffscreenVisualisation`), so the player can cast them to a TV, and input plugins can offer live video encoders (`IVideoEncoderFactory`). The PeakMeter sample shows how. SDK 0.4.1 added encoders for cast transcoding.

- The Windows build now needs Windows 10 version 1809 or later, and includes Microsoft's Windows SDK projection (`Microsoft.Windows.SDK.NET.dll`, Windows SDK license) for the media controls.
- The player decodes 1 second ahead instead of half a second, so a busy computer (installers, updates) is much less likely to cause a dropout. A speed change now takes effect about half a second later.

## Known issues

- On one test PC the Windows media box went empty (no app name or title) and media keys stopped reaching AudioTastic after installing and uninstalling the setup; other programs could not query Windows' media sessions either. Not yet reproduced elsewhere; under investigation.

## Fixed

- When the last audio device disappears (a Remote Desktop session ends, the only USB DAC is unplugged), playback now pauses where it is and continues by itself when a device is back, instead of stopping.
- Damaged files no longer cause errors (found by testing with thousands of deliberately damaged files and network messages): a playlist line with a null character or an absurd length, a PLS file with odd entry numbers, Ogg and other files whose tags TagLib cannot read (now simply shown without tags), a broken mDNS answer from any device on the network (it could stop the Chromecast search), a broken Cast message or status from a Chromecast, and an impossible position from a DLNA TV.
- AudioTastic could close without warning when another program (an antivirus scanner, the Windows search indexer, a backup tool) briefly held its settings file open while it saved the volume. Saving now waits a moment and tries again; if the file stays busy the change is kept and saved with the next one.
- In the DSP chain window a left click on an effect only switched it on or off; it now also selects it, so its details (*Open editor*, *Remove from chain*) show.
- The playlist drew rows for only part of its height at player sizes above 100 % until it was resized or scrolled.
- The format badges (WAV, 16 BIT, …, STEREO) were cut off at the right edge when they did not fit; the row now shrinks slightly to keep every badge whole.
- *Main menu › Open folder…* and the playlist's *ADD › Add URL…* were always greyed out; they now add a folder (and play it) and an internet radio address.
- The parametric equalizer's *Bands…* table cut off five-digit frequencies and the delete buttons; it is now wide enough and has column headings.
- *Settings › System integration* still said notifications would arrive later; they are on the Interface page.
