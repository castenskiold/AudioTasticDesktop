AudioTastic 0.10.0 (in progress, not released yet) adds the first part of system integration (phase P10).

## New

- **Single instance:** AudioTastic runs once per user. Opening files while it runs sends them to the running player, which brings itself to the front. Files opened together, e.g. several selected in Explorer, are added as one batch, sorted by path.
- **Notifications (Windows):** optional notification with the title, artist and cover when the track changes, skipped while AudioTastic is in front (*Settings › Interface*, off by default).
- **Taskbar (Windows):** previous / play-pause / next buttons under the taskbar preview, and green (playing) or yellow (paused) progress on the taskbar button, which can be switched off.
- **Global hotkeys (Windows):** Ctrl+Alt+Home play/pause, Ctrl+Alt+End stop, Ctrl+Alt+PgUp/PgDn previous/next and Ctrl+Alt+Up/Down volume work while another program is in front. Switch them off or change them (twelve actions) in *Settings › System integration › Global hotkeys*; a combination another program already uses is marked.
- **Media controls (Windows):** AudioTastic shows in the Windows media flyout with the title, artist and cover (or its logo); the flyout's buttons, keyboard media keys and headset buttons control it, even when it is hidden. A Start menu shortcut is created (needed for Windows to show the app's name; switch it off in *Settings › System integration*).
- **Tray icon:** hover for the title, click to hide or show the player with its docked windows, right-click for Play/Pause, Stop, Previous, Next, a sleep timer (15 minutes to 2 hours, end of track or playlist), Show/Hide and Exit. Optional minimise and close to the tray (*Settings › System integration › Tray*).
- **File types (Windows):** the first start asks whether to use AudioTastic for audio files. *Yes, set up* registers it for every audio and playlist type it plays and opens *Settings › Default apps*, where you make it the default; double-clicked files then go to the running player. *Settings › System integration › Choose default apps…* does the same later; switching the registration off removes it.
- **Explorer context menu (Windows):** *Open in AudioTastic* (adds the files and plays the first) and *Enqueue in AudioTastic* (adds them to the end of the playlist), with the app icon, for every audio and playlist type the enabled plugins support. On Windows 11 they are under *Show more options*. Per user, no administrator rights; switch them off in *Settings › System integration* before deleting the program.
- **Command line:** files with `--open` or `--enqueue`, and player commands for scripts and shortcuts: `--play`, `--pause`, `--playpause`, `--stop`, `--next`, `--prev`, `--volume N`, `--seek s`, `--quit`. They go to the running player (or start it). On Windows they can also be written `/next`, `/volume 40`. `--help` and `--version` print to the console.
- **Settings › System integration:** files opened from the file manager or the command line are played (default) or enqueued; the context menu on/off (off by default in portable mode).

- **Resizing snaps:** resizing the playlist or Art & Lyrics window by its corner lines its right and bottom edges up with the player and other windows (and the screen edge) within 10 px, like moving does.

## Changed

- The Windows build now needs Windows 10 version 1809 or later, and includes Microsoft's Windows SDK projection (`Microsoft.Windows.SDK.NET.dll`, Windows SDK license) for the media controls.

## Fixed

- The playlist drew rows for only part of its height at player sizes above 100 % until it was resized or scrolled.
- The format badges (WAV, 16 BIT, …, STEREO) were cut off at the right edge when they did not fit; the row now shrinks slightly to keep every badge whole.
