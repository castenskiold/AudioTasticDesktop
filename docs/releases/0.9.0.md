AudioTastic 0.9.0 is the first public release: a Winamp-style audio player with DJ-style crossfading and beat matching, plugins, skins, an equalizer and DSP chain, album art, lyrics and tag editing.

## Downloads

| Platform | File | Tested |
|---|---|---|
| Windows x64 | `AudioTastic-0.9.0-win-x64.zip` | Yes (daily use) |

| macOS Intel | `AudioTastic-0.9.0-osx-x64.tar.gz` | Builds; not tried on a device |

| OptimFROG plugin (optional) | `AudioTastic.Input.OptimFrog.atplugin` | Windows x64, Linux x64, macOS Intel |

Unpack the archive anywhere and run `AudioTastic` (`AudioTastic.exe` on Windows). There is no installer yet; it comes with the next phase. Settings are kept in your user profile, or next to the program with `--portable`.

- **Windows:** this build is not code-signed yet (signing through the SignPath Foundation is being applied for), so SmartScreen may warn that the publisher is unknown: choose *More info › Run anyway*.
- **macOS:** the app is not signed or notarized. After unpacking, run `xattr -dr com.apple.quarantine <folder>` once, or allow it in *System Settings › Privacy & Security*.
- **Linux:** needs a desktop with X11 or XWayland.

## Optional downloads

- **OptimFROG (.ofr) playback:** install `AudioTastic.Input.OptimFrog.atplugin` with *Settings › Plugins › Install*. It contains the closed-source freeware OptimFROG libraries by Florin Ghido (license included), which is why it is not part of the app.
- **MIDI playback:** the MIDI plugin downloads the GeneralUser GS SoundFont when you click *Download* in its settings (or use any .sf2).

## Known limitations

- Not yet tried by hand on macOS and Linux; please report problems.
- Beat matching sounds right on most tested tracks, but a few transitions are still off; *Adjust beat grid…* in the playlist menu fixes a track by hand.
- System integration (single instance, file associations, media keys, tray, taskbar) and the installer come in the next phase.
