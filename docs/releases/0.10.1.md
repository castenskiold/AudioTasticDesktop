Also attached: the optional OptimFROG plugin (`AudioTastic.Input.OptimFrog.atplugin`, Windows x64, Linux x64, macOS Intel; install it with *Settings › Plugins › Install*), the sources of the bundled FFmpeg libraries (`AudioTastic-0.10.1-ffmpeg-sources.tar`), and `SHA256SUMS.txt` with the checksums of every file.

- **Windows:** the setup installs for your user only (no administrator rights) and adds Start menu entries for AudioTastic and the User Manual. The portable zip keeps settings next to the program. Neither is code-signed yet, so SmartScreen may say the publisher is unknown: choose *More info › Run anyway*.
- **macOS:** open the `.dmg` and drag AudioTastic to Applications. The app is not signed or notarized: allow it once in *System Settings › Privacy & Security*, or run `xattr -dr com.apple.quarantine /Applications/AudioTastic.app`.
- **Linux:** make the AppImage executable (`chmod +x`) and run it; needs a desktop with X11 or XWayland.

Upgrading from 0.10.0: install over it (or replace the portable folder); your settings and playlists are kept.

## New

- **User Manual:** every window, menu, dialog and setting, with screenshots. Read it [on GitHub](https://github.com/castenskiold/AudioTasticDesktop/blob/main/docs/manual/README.md) or as a PDF: `AudioTastic User Manual.pdf` ships next to the program, and the Windows setup adds it to the Start menu.

## Fixed

- *Main menu › Open folder…* and the playlist's *ADD › Add URL…* were always greyed out. Open folder… now adds a folder (with its subfolders) and plays it; Add URL… adds an internet radio address without starting it.
- The parametric equalizer's *Bands…* table cut off five-digit frequencies and the delete buttons. It is now wide enough and has column headings (Type, Frequency, Gain, Q).
- *Settings › System integration* still said notifications would arrive later; it now points to the Interface page, where they are switched on.
